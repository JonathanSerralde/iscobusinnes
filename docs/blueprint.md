# **App Name**: ICCI Iberica

## Core Features:

- Informative Sections: Display static content for 'Nosotros' (About Us), 'Oferta Formativa' (Training Offers), 'Servicios' (Services), and 'Contacto' (Contact) sections.
- Aula Virtual Access: Allow users to log in to the virtual classroom via a secure authentication form.
- Image Integration: Replace placeholder images from https://dummyimage.com/ with actual relevant images to enhance the visual appeal and SEO of the site. Use next/image to optimize for different screen sizes.
- SEO Content Optimization: Use a tool to analyze the existing website content from 'iberica.mx' and suggest optimized content variations for SEO, SEM, and AEO, incorporating relevant keywords and metadata.

## Style Guidelines:

- Primary color: Crimson (#B71C1C) to reflect the institution's branding and create a sense of trust and importance.
- Background color: Light gray (#F5F5F5) to provide a clean and neutral backdrop that ensures readability.
- Accent color: Dark red (#8E0000) for call-to-action buttons and important links, providing a clear visual hierarchy.
- Body font: 'PT Sans', a humanist sans-serif, providing a balance of modernity and warmth for readability.
- Headline font: 'Playfair', a modern serif with an elegant feel, for headlines; use 'PT Sans' for body text.
- Use clear, professional icons in a dark gray to represent services and offerings. Consistent style to maintain a unified appearance.
- Implement a clean, well-organized layout using Tailwind CSS grid and flexbox. Ensure responsiveness across devices.
- Subtle transitions and hover effects to provide visual feedback and enhance user engagement.
