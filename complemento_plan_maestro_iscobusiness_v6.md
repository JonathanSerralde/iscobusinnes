# 2. Criterio editorial adicional para el portal matriz

El paquete V6 introduce una definición muy útil para la posición institucional del portal principal:

> **ISCOBUSINESS debe presentarse como la organización de la sociedad civil que da dirección, coherencia y sentido público a un ecosistema de unidades especializadas.**

Esto debe complementar la arquitectura ya definida.

## 2.1. Regla editorial

El portal matriz:

- **no debe competir** con los portales de sus unidades;
- **no debe duplicar** los catálogos o procesos especializados;
- debe explicar:
  - propósito común;
  - objeto social;
  - modelo de impacto;
  - estructura institucional;
  - formas de participación;
  - relación entre las unidades;
  - mecanismos de transparencia;
  - conocimiento producido;
  - cooperación y alianzas.

## 2.2. Posicionamiento que debe evitarse

El portal principal **no debe parecer únicamente**:

- una escuela;
- una plataforma de cursos;
- un catálogo comercial;
- una página exclusiva de certificación;
- una landing page de ventas.

Debe conservar capacidad de conversión, pero dentro de una narrativa institucional más amplia.

## 2.3. Principio de verificabilidad

La comunicación debe ser:

- clara;
- sobria;
- comprensible;
- verificable;
- trazable.

Las cifras de impacto, cuando se publiquen, deben acompañarse de:

- fuente;
- fecha de corte;
- metodología;
- alcance;
- responsable;
- limitaciones cuando existan.
